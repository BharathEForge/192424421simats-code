## 🧠 EDU-PIVOT

### Intelligent Adaptive Learning & Dropout-Risk Intervention System

An AI-driven learning platform designed to identify declining student engagement, estimate dropout risk, and recommend personalized learning or career pathways.

### How it works

```text
┌─────────────────────┐
│   Student Activity  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Learning Behaviour  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Engagement Signals  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Performance Analysis│
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│   Dropout Risk      │
│     Prediction      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Personalized        │
│ Intervention        │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Learning / Career   │
│      Pivot          │
└─────────────────────┘
```

### Key capabilities

* 📊 Student performance and progress analysis
* 🧠 Dropout-risk prediction
* 😊 Engagement and behavioural signals
* 🎯 Personalized interventions
* 🎮 Gamified learning mechanisms
* 🔄 Adaptive learning pathways
* 🚀 Cross-domain career recommendations

**Domain:** `AI` `EdTech` `Predictive Analytics` `Recommendation Systems`

## 🦷 PediPredict

### Pediatric Dental Cooperation & Anxiety Prediction

A healthcare-oriented ML application designed to estimate **pediatric dental cooperation and anxiety risk** using a combination of patient responses and behavioural / visual signals.

### System pipeline

```text
Patient Responses
       +
Behavioural Signals
       +
Visual Signals
       ↓
Machine Learning
       ↓
Anxiety / Cooperation Analysis
       ↓
Risk Classification
       ↓
Patient History
       ↓
Clinical Decision Support
```

### Key capabilities

* 🧠 ML-based risk prediction
* 👁️ Computer vision integration
* 📋 Patient self-assessment
* 📈 Risk classification
* 🗂️ Patient history management
* 🏥 Healthcare decision support

**Domain:** `Healthcare AI` `Machine Learning` `Computer Vision`
